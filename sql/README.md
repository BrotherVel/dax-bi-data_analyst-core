# 🗄️ SQL

Esta seção reúne exemplos práticos e conceitos fundamentais de **SQL Server**, organizados de forma progressiva para facilitar o aprendizado e a consulta.

Os scripts abrangem desde operações básicas de definição e manipulação de dados até alterações na estrutura de tabelas, servindo como material de apoio para estudos e referência.

Grande parte dos estudos utiliza como base o banco de dados **AdventureWorksDW2025**, disponibilizado neste repositório, permitindo praticar consultas e comandos SQL em um ambiente próximo de cenários reais.

## Conteúdo

- **01** - CREATE TABLE: tipos básicos e chave primária
- **02** - CREATE TABLE: relacionamentos com chave estrangeira
- **03** - INSERT INTO: inserção de registros
- **04** - UPDATE: atualização de dados e utilização do `WHERE`
- **05** - DELETE FROM: remoção de registros
- **06** - DROP COLUMN: exclusão de colunas
- **07** - ADD COLUMN: adição de colunas
- **08** - ALTER COLUMN: alteração de tipos de dados
- **09** - SELECT: consultas básicas, seleção de colunas, `DISTINCT`, operações simples, `TOP` e `TOP WITH TIES`

> 🚧 Esta documentação está em constante evolução e novos tópicos serão adicionados conforme o repositório for sendo desenvolvido.
