# 📊 DAX & SQL Core

> Uma base de conhecimento dedicada a SQL e DAX, construída continuamente para organizar, consolidar e compartilhar conhecimento de forma prática.

---

# 📖 Sobre o projeto

Este repositório nasceu com o objetivo de reunir, organizar e documentar conhecimentos sobre **SQL** e **DAX** em um único lugar.

O conteúdo é construído gradualmente a partir de diferentes fontes, como:

- 📚 Documentação oficial
- 🎓 Cursos e treinamentos
- 📝 Anotações pessoais
- 💼 Experiência prática e resolução de problemas reais

Mais do que um material de estudos, este projeto busca se tornar uma base de consulta organizada, contendo conceitos, exemplos e soluções que possam ser úteis tanto para mim quanto para outros profissionais e estudantes da área de dados.

---

# 🚧 Projeto em desenvolvimento

Este repositório está em constante evolução.

À medida que novos temas forem sendo considerados relevantes, novas seções, exemplos e documentações serão adicionados. A própria estrutura do projeto continuará sendo refinada conforme a necessidade e a maturidade do conteúdo.

São conhecimentos comuns nos quais estou bem familiarizado, entretanto a estruturação desse conhecimento aqui será gradativa.
Por esse motivo, caso houver ausência de determinado assunto, provavelmente é porque ainda não foi incorporado à documentação deste repositório, mas está em planejamento.

# 📂 Estrutura

## 🗄️ SQL

A seção de SQL tem como objetivo reunir consultas, comandos e conceitos fundamentais utilizados no dia a dia.

Entre os conteúdos previstos estão:

- Consultas básicas e avançadas
- Joins
- Subqueries
- CTEs
- Window Functions
- Views
- Procedures
- Modelagem de dados
- Boas práticas
- Performance

---

## 📈 DAX

A seção de DAX reúne conceitos, funções e medidas desenvolvidas principalmente para Power BI.

O foco é apresentar aplicações práticas e explicar o raciocínio por trás de cada solução.

Os conteúdos incluem:

- Medidas básicas
- Contexto de filtro e contexto de linha
- CALCULATE
- Funções iteradoras
- Variáveis
- Inteligência temporal
- Otimização de medidas
- Casos de negócio
- Boas práticas
